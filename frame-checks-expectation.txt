frame-checks-expectation.txt: registered at M0, before any src change for frame-sequence sweeps

Flag under test: FREERANGE_SWEEP=1 FREERANGE_SWEEP_FRAMES=1. For comparisons, FREERANGE_ASSERT_FORMS=1 FREERANGE_STATIC_RELATIONS=1 FREERANGE_IMPORTED_CALLS=contract are also set, with and without FREERANGE_SWEEP_FRAMES.
Defaults: maxFrames 64, framesPerEntry 1,000,000, sequencesPerEntry 100,000, stepBudget 1,000 per frame, redraws 8, shrinkRuns 2,000.

COUNTING RULES
- sequence: one counted driver run. It returned, with no discard, over-budget, throw, R1 or wrotePrevious, after any redraws or truncation.
- frames: the summed events-array lengths of counted sequences.
- reaching: counted sequences in which the site executed.
- failing: reaching sequences at recorder level >= 3.
- flagged file: at least one stdout finding with rule console-assert-sweep or internal, carrying an `input:` line whose function is a frame driver. Static findings are excluded and counted separately.
- quiet file: no console-assert-sweep warning and no internal error on stdout.
- shrunk length: events in the printed input.
- time: `/usr/bin/time -l` real seconds of `bun fr.ts <file>`.
- child RSS: max of JSON timing.run.peakRssKb and timing.verify.peakRssKb.
- replay-reproduced: the independent oracle (a fresh bun process that imports the original file and overrides console.assert) fires the printed site's line on the printed input.
- Probe numbers below come from a standalone probe script. It runs in-process, with narrowing emulated by a text parse, and has no child or verification. Implementation counts must match detection yes/no, and land within 0.5x-2x of the probe's failing counts at the same settings, or the difference is explained in the results.

C. HELD-OUT SYNTHETIC SET: 12 pairs (24 files). Count fixed.
Written by a separate agent that does not implement fr. The implementer sees neither version until the prototype commit is frozen, and that hash is recorded here before the run. One pair per domain, fixed now:
1. virtual list keeps the first visible row in place while rows above load (anchoring)
2. zoomable map keeps the point under the cursor within 0.5 px (anchoring, tolerance)
3. drag-reorder list stores the drop index the list actually applied after clamping (stored vs applied)
4. carousel stores the index the snap settled on, not the one requested (stored vs applied)
5. timeline scrubber refreshes its cached pixels-per-second on zoom or resize (cache refresh)
6. text-measurement cache keyed on font size and text length (cache refresh)
7. physics step with bounded speed and a wall clamp keeps position inside the world (state invariant)
8. grid selection: a pointer move onto the already selected cell returns the same model object (render identity)
9. autosave debouncer: pending edits always have a timer scheduled (missing wake)
10. toast stack: at most 3 visible, and the stored visible count equals what was laid out (stored vs applied)
11. audio level meter: a silent frame after decay has finished doesn't bump the render counter (render counter)
12. spreadsheet column resize keeps the cell under the pointer in place while widths to its left change, unless the user scrolled (anchoring)

Authoring rules:
- the driver shape of spec section 2.1;
- correct and buggy versions differ in at most 3 lines of app code, never in driver, model or asserts;
- every bug has a hand-written failing sequence of at most 8 events inside the file's bounds, sealed with oracle output (buggy fires, correct doesn't);
- each correct version is checked by the author's own random runner (not fr) over 100,000 sequences of up to 64 events, with 0 firings.

Metrics and thresholds:
- M-detect: flagged buggy files at defaults >= 10 of 12. Also report the count at 10x framesPerEntry.
- M-quiet: flagged correct files = 0 of 12.
- M-replay: replay-reproduced printed counterexamples = 100% (every one).
- M-shrink: median shrunk length <= 2x the sealed hand-minimal length.
- M-first: sequences before the first failure (JSON first.index), reported per file, no threshold.
- M-today: files flagged by FREERANGE_SWEEP=1 alone, through an input reproducing the sealed bug, <= 3 of 12.
- M-static: static error findings on driver files, reported (informational; owner decision).
- M-time: median <= 3 s and max <= 10 s per file; child RSS <= 400 MB per file.

D. MUTANTS (dev correct versions)
- Operators: stale input, off-by-one, swapped min/max, dropped clamp, `<` to `<=`.
- Each operator is applied once at its first applicable site in camera_ok, editor_ok, chart_ok, queue_ok, layout_ok and zoom_ok: at most 30 mutants. The adversarial agent generates them, and the final count is recorded before the run.
- A mutant is non-equivalent if the oracle finds a firing within 100,000 sequences at L=256, or a hand sequence fires.
- Thresholds: flagged >= 80% of non-equivalent mutants at defaults; flagged = 0 equivalent mutants.

E. ADVERSARIAL ROUND: N = 30 probes, fixed.
- Probes: S1-S22 from the spec plus at least 8 free-form probes.
- Thresholds, all 0:
  - printed counterexamples not replay-reproduced;
  - internal errors without a real contradiction (a finite, leading-assert-meeting direct call firing a proven line);
  - held results on planted bugs with p >= 1% per sequence within 8 events under the printed domain (p estimated by the oracle over 10,000 sequences);
  - verified driver failures at proven sites reported JSON-only.

F. FLAG AND COST
- Flag off: findings and JSON byte-identical to explore/combined on every existing test fixture and every file in A and C.
- Flag on, files without a driver: findings byte-identical to flag off (the adversarial probe files and existing sweep fixtures).
- Flag on, any file: static findings byte-identical to flag off.
- `bun test`, pre-existing tests only: median of 3 wall times <= 1.10x the M0 baseline median on the same machine.
- `bun run check` green.

STOP CONDITIONS (the prototype doesn't advance; results reported as-is)
- M-quiet > 0 without a documented model false alarm confirmed by the author;
- any E threshold violated and unresolved;
- M-replay < 100%;
- any flag-off difference;
- M-detect < 10 of 12.
