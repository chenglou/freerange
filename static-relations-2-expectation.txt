Static relations, second exploration: scope registered before any code.

Mode: unchanged. Every new rule runs only with FREERANGE_STATIC_RELATIONS=1, and only inside the proofs of interior console.assert conditions and join-fact verification. Leading requirements, requirement inference and ordinary analysis keep main's rules.

Targets, in build order:
1. Exact integer linear forms. Under the integer-safe gate every + - and * by an integer constant is exact, so a comparison reduces to the sign of an integer linear form over leaf values. The proof splits Math.min and Math.max leaves into their operands, substitutes bounds from order and join facts, and ends at interval lower bounds. It never invents a computed value.
2. Arm splitting at the assertion. A compared value that is a parameter of a block outside every cycle is proved on each incoming edge argument separately.
3. Return relations (cut from the first prototype). A completed same-file call publishes, as assertion-only facts, the order between its numeric return value and each numeric argument that holds on every return path of the callee's evaluation.
4. Join facts at loop headers (cut from the first prototype). Loop headers propose and re-verify join facts like other joins, with bounds produced outside every cycle. A change that only drops join facts does not count toward the 16-update backstop.

Gates:
- no proof is lost against main or against the first prototype, and no assertion that can be false is reported proved
- fr --audit requires, ensures and assumes lines are identical to main's
- per file: wall time at most 2x main, max RSS at most main + 100 MB
- generated probe and fuzz functions report no unsound verdict, and the mutants that detected holes before still detect them

Caps, each failing closed with a test that hits it: linear form leaves and coefficient size, linear substitution depth, arm split depth and edges per split, return relation parameters and return blocks, join-fact-only loop header updates.
